🏥 The Healthcare Payer Dilemma

At an enterprise scale of 1,000,000 claims/day, healthcare claims adjudication pipelines face a fundamental architectural trade-off:

  • Brittle Rule Engines & Regex: Blind to nuanced clinical narratives, generating high false-positive audit rates and nurse reviewer fatigue.
  • Generative LLM Chat Completions: Accurate but slow (~2,500ms latency) and costly, generating 115+ unnecessary prose tokens on routine, unambiguous encounters.

The Solution: Pair ultra-fast single-pass classification with on-demand generative clinical rationale.

🤖 OpenAI Model Architecture Bake-Off

The demo compares two distinct inference paradigms across OpenAI frontier models:

  • System 2 (Generative LLM): OpenAI Chat Completions (GPT-6 Sol) using Strict Structured Outputs (response_format: json_schema). Generates routing decisions plus full clinical_rationale (~115 tokens out). Pricing: $2.00 / 1M input, $10.00 / 1M output.
  • System 1 (Direct Classifier): OpenAI Decisions API. Single forward-pass evaluation across 3 structured questions with calibrated probabilities and zero token generation ($0.10 / 1M input).
  • True Paradigm Comparison: Both leverage frontier model capabilities; speed and cost gains derive from the inference paradigm.
⚡ The OpenAI Confidence-Gated Cascade
  • System 2 Baseline (GPT-6 Sol): Autoregressive JSON generation (~115 tokens, ~2,500ms). Full reasoning trace for audits.
  • System 1 Innovation (Decisions API): Single forward-pass evaluation (~100ms, 0 tokens generated, $0.10/M tokens). Rapid probability scoring.
  • Confidence Gate (Threshold ≥ 0.90): System 1 handles ~80% clear-cut volume in ~100ms. Ambiguous edge cases (<0.90) dynamically escalate to OpenAI Chat Completions (GPT-6 Sol) to generate clinical rationale for nurse auditor review.

🎯 3-Question Rubric in OpenAI Schema

Evaluated simultaneously in a single API transaction:

  • 1. Routing Queue (type: "choice"):
    auto_adjudicate · clinical_nurse_review · coding_audit_ncci · cob_subrogation · siu_fraud_review
  • 2. Missing Docs (type: "predicate"):
    Calibrated probability that operative summaries, pathology, or imaging discs are omitted (yes vs. no).
  • 3. Urgency Tier (type: "score"):
    Turnaround compliance: standard_30_day, expedited_72_hr, stat_24_hr.
🔬 OpenAI Decisions API: Zero-Generation Scoring
  • Zero Output Tokens: Eliminates autoregressive text generation. Directly scores probability mass across target schema choices in a single forward pass.
  • Calibrated Probabilities: Delivers full categorical probability distributions (queue_probabilities, urgency_probabilities) and predicate likelihood.
  • Normalized Confidence Metric:
    C = (K · p_max - 1) / (K - 1) ∈ [0, 1]
    Normalizes multi-class distributions ($K=5$) so uniform uncertainty ($p=0.20$) yields $C=0.0$.
⚡ Strict Structured Outputs & Caching
  • OpenAI Strict JSON Schema: response_format: {"type": "json_schema", "strict": true} guarantees 100% adherence to Pydantic models with zero parse errors.
  • Generative Clinical Rationale: Escalated claims receive a 2-sentence rationale trace detailing coding discrepancies or missing clinical records for nurse auditors.
  • OpenAI Prompt Caching: Repetitive rubric instructions and system prompts automatically benefit from prompt prefix caching discounts and sub-150ms evaluation.
